# 收款码

把收款码图片放在这里，打包时会一起带上：

- `wechat.png`（或 .jpg）：微信收款码
- `alipay.png`（或 .jpg）：支付宝收款码

只放一种也可以，弹窗会自动隐藏切换按钮。

不重新打包也能换：把 `donate-wechat.png` / `donate-alipay.png` 放到 `WeReadMini.exe` 同一个文件夹里，会优先使用这两张。

## 小红书图标（可选）

打赏弹窗底部“反馈与新版本”那一行默认用一个中性的对话气泡图标。放一张 `xhs.png`（或 .jpg，正方形，32×32 以上）到这里，或把 `donate-xhs.png` 放到 exe 同一个文件夹，就会换成这张图标。
