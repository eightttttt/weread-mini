# 微信读书小窗（WeReadMini）

把[微信读书网页版](https://weread.qq.com/)装进一个可以随时在桌面上看的小窗口。基于 Electron，支持 Windows 和 macOS。

> 本项目只是微信读书网页版的一个桌面外壳，与腾讯 / 微信读书官方无关。书籍内容和账号都来自微信读书网页版本身。

## 功能

- **桌面小窗**：窗口小巧、可置顶，不占任务栏 / Dock，只在系统托盘 / 菜单栏
- **界面极简**：去掉网页的顶栏、书名章节行、翻页按钮和两侧大留白，正文铺满窗口
- **点击翻页**：点窗口左侧约 1/3 上一页，右侧约 1/3 下一页
- **自动翻页**：自动识别阅读方式——左右翻页时定时翻页，上下滚动时匀速滚动
- **播报条**：把正文排成一行向左滚动，像新闻播报条；窗口收成细长条，默认透明背景，速度和字号可调，按钮暂停，自动续页
- **鼠标移开自动隐身**：鼠标离开立即完全透明且不挡鼠标，移回即出现
- **记住阅读位置**：返回书架再进入时，回到每一章原来读到的那一页
- **阅读色调**：原色 / 护眼 / 豆沙绿 / 夜间 / 透明（书页背景全透明，文字浮在桌面上）
- **磨玻璃工具栏**：Windows 11 / macOS 上透出后面模糊的桌面
- **沉浸模式**：工具栏自动隐藏，鼠标移到窗口顶端才浮出
- **收纳式菜单**：书页左下角返回书架，右下角 ☰ 收纳目录、笔记、切换阅读方式、字号、主题

## 快捷键

| 功能 | Windows | macOS |
| --- | --- | --- |
| 显示 / 隐藏小窗（全局） | Alt+Q | ⌥Q |
| 自动翻页 开 / 停（全局） | Alt+P | ⌥P |
| 播报条 开 / 关（全局） | Alt+L | ⌥L |
| 自动翻页 / 播报条 加快 / 减慢（全局） | Alt+] / Alt+[ | ⌥] / ⌥[ |
| 下一页 / 上一页（全局） | Alt+→ / Alt+← | ⌥→ / ⌥← |
| 窗口不透明度（全局） | Alt+↑ / Alt+↓ | ⌥↑ / ⌥↓ |
| 字体放大 / 缩小 / 恢复 | Ctrl + = / - / 0 | ⌘ + = / - / 0 |
| 切换阅读方式 | Ctrl+M | ⌘M |
| 阅读色调 | Ctrl+T | ⌘T |
| 沉浸模式 | Ctrl+H 或 F11 | ⌘H |
| 关闭弹窗 / 退出沉浸模式 | Esc | Esc |
| 拖动窗口 | 按住 Alt 拖动 | 按住 ⌥ 拖动 |
| 调整窗口大小 | 拖动右下角 | 拖动右下角 |

## 开发

需要 Node.js 18 或更新版本。

```bash
npm install      # 安装依赖
npm start        # 本地运行
```

## 打包

```bash
npm run pack:win   # 生成 dist/WeReadMini-win32-x64/WeReadMini.exe
npm run pack:mac   # 生成 distmac/ 下的苹果芯片版和 Intel 版
```

Mac 版没有苹果开发者签名。第一次打开前需要在 Mac 上执行一次：

```bash
xattr -cr /Applications/微信读书小窗.app
codesign --force --deep --sign - /Applications/微信读书小窗.app
```

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `main.js` | 主进程：窗口、托盘、快捷键、自动翻页、隐身、设置保存 |
| `bar.html` + `preload.js` | 顶部工具栏 |
| `inject.js` | 注入到微信读书页面：窄边距排版、点击翻页、收纳菜单、记住阅读位置 |
| `page-preload.js` | 书页里按住 Alt / ⌥ 拖动窗口、拖右下角调整大小；记录网页画到画布上的文字（供播报条使用） |
| `ticker.html` | 播报条（单行滚动） |
| `build/extra.plist` | macOS 打包用的 Info.plist 补充项 |
| `icon.*`、`tray*.png` | 应用图标和托盘 / 菜单栏图标 |
